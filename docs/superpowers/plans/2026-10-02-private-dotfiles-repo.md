# Private dotfiles repo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split host-specific packages and local/include files out of the public `~/dotfiles` repo into a new, independent, plaintext-private `~/dotfiles-private` repo that stows into `$HOME` the same way.

**Architecture:** Two independent GNU Stow repos targeting `$HOME`, each with its own self-contained `make install`. The private repo holds the 12 `<tool>-<host>` packages plus a shared `local/` package and per-host `local-<host>/` packages for the include files. The public base (`bash_common`, `gitconfig`, `ssh/config`) is edited to source/include both the shared and per-host local files.

**Tech Stack:** GNU Stow, GNU Make, bash, git, ssh config, POSIX filesystem ops.

**Spec:** `docs/superpowers/specs/2026-10-02-private-dotfiles-repo-design.md`

## Global Constraints

- Secrets are stored plaintext in the private repo; no encryption. Security rests on repo privacy. (spec: Decisions)
- The public repo must contain nothing that names or references the private remote. (spec: Decisions)
- Host-scoping convention: packages suffixed `-<host>`; `HOSTS := io europa helios`; a host stows shared packages plus only packages matching `hostname -s`. (spec: Private repo package layout)
- The private Makefile is a copy of the public engine with the public-only bootstrap line (`curl … localdev/install.sh | bash`) omitted. (spec: Makefile)
- Commits: the public repo is left uncommitted (first commit is the user's to shape — repo currently has 0 commits). The private repo gets an initial local commit; creating the private GitHub remote and pushing are user steps. (user instruction: commit only when asked)
- No `migrate.sh` is introduced; migration is the steps in this plan. Do not add the README disclaimer blurb (README already exists without it). (user CLAUDE.md)
- Emoji characters are forbidden in code and config. (user CLAUDE.md)

## Review Focus

- **Host not in {io,europa,helios}:** `make install` must still stow shared packages and simply select no host packages, without error. (pinned in Task 7)
- **Public present, private absent (and vice versa):** the public base must load with no errors — missing SSH `Include`, missing `git include.path`, and `[[ -f ]]`-guarded env sources all degrade silently. (pinned in Task 7, Step 2)
- **SSH first-match ordering:** a host entry in `~/.ssh/config.d/<host>.conf` must take precedence over the generic `Host *` block — the `config.d` Include must appear before `Host *` in the file. (pinned in Task 6, structural check)
- **Empty `local-<host>/` package:** a per-host package with no files must refresh/stow with no error and create no stray targets. (pinned in Task 7)
- **Idempotent re-install:** running `make install` twice in a row must leave correct symlinks and report no conflicts. (pinned in Task 7)

- [ ] **Step 3: Verify the bootstrap line is gone and HOSTS is intact**

Expected: first prints `0`; second prints the `HOSTS := io europa helios` line.

- [ ] **Step 4: Create `.stowrc` (target = $HOME, same as public)**

### Task 5: Scaffold per-host `local-<host>/` packages

**Files:**
- Create: `~/dotfiles-private/local-{io,europa,helios}/.config/work.local.env`
- Create: `~/dotfiles-private/local-{io,europa,helios}/.ssh/config.d/<host>.conf`
- Create: `~/dotfiles-private/local-{io,europa,helios}/.gitconfig.host`

**Interfaces:**
- Produces: one host-scoped `local-<host>` package per host, each carrying empty-but-tracked override files ready for host-specific content. Only the package matching `hostname -s` is stowed on a given host.

- [ ] **Step 1: Create the three per-host packages with placeholder-free stub files**

```bash
for h in io europa helios; do
  d=~/dotfiles-private/local-"$h"
  mkdir -p "$d/.config" "$d/.ssh/config.d"
  printf '# %s-only env overrides (sourced after shared work.env)\n' "$h" > "$d/.config/work.local.env"
  printf '# %s-only SSH entries (Included before Host *; first match wins)\n' "$h" > "$d/.ssh/config.d/$h.conf"
  printf '# %s-only git overrides (included after ~/.gitconfig.local)\n' "$h" > "$d/.gitconfig.host"
done
```

- [ ] **Step 2: Verify each package's layout**

Run:
```bash
for h in io europa helios; do echo "== local-$h =="; find ~/dotfiles-private/local-"$h" -type f | sort; done
```
Expected: each `local-<host>` lists `.config/work.local.env`, `.gitconfig.host`, `.ssh/config.d/<host>.conf`.

Note: content-splitting (moving host-specific entries out of the shared `local/` files into these per-host files) is a manual follow-up the user performs as needed; the stubs make the destinations exist.

### Task 6: Edit the public base to consume shared + per-host local files

**Files:**
- Modify: `~/dotfiles/bash/.bash_common` (after the `work.env` source line)
- Modify: `~/dotfiles/git/.gitconfig` (the `[include]` section)
- Modify: `~/dotfiles/ssh/.ssh/config` (after the existing `Include ~/.ssh/config.local`)

**Interfaces:**
- Consumes: `work.local.env`, `~/.ssh/config.d/*.conf`, `~/.gitconfig.host` provided by the private repo's `local-<host>` packages.
- Produces: a public base that loads the per-host overrides when present and degrades silently when absent.

- [ ] **Step 1: bash_common — source the per-host env after the shared one**

In `~/dotfiles/bash/.bash_common`, change:
```bash
# Source work-specific env (credentials, internal hostnames — not tracked in git)
[[ -f ~/.config/work.env ]] && source ~/.config/work.env
```
to:
```bash
# Source work-specific env (credentials, internal hostnames — not tracked in git)
[[ -f ~/.config/work.env ]] && source ~/.config/work.env
# Host-specific overrides live in the private repo's local-<host> package.
[[ -f ~/.config/work.local.env ]] && source ~/.config/work.local.env
```

- [ ] **Step 2: gitconfig — add the host include after the shared one**

In `~/dotfiles/git/.gitconfig`, change:
```
[include]
	path = ~/.gitconfig.local
```
to:
```
[include]
	path = ~/.gitconfig.local
	path = ~/.gitconfig.host
```

- [ ] **Step 3: ssh config — add the host-specific Include directory glob**

In `~/dotfiles/ssh/.ssh/config`, change:
```
# Put sensitive hosts (IPs, internal infra) in ~/.ssh/config.local
Include ~/.ssh/config.local
```
to:
```
# Put sensitive hosts (IPs, internal infra) in ~/.ssh/config.local
Include ~/.ssh/config.local
# Host-specific entries from the private repo's local-<host> package.
# Placed before Host * so they win under SSH first-match semantics.
Include ~/.ssh/config.d/*.conf
```

- [ ] **Step 4: Verify the three edits are present**

Run:
```bash
grep -n 'work.local.env' ~/dotfiles/bash/.bash_common
grep -n 'gitconfig.host' ~/dotfiles/git/.gitconfig
grep -n 'config.d/\*.conf' ~/dotfiles/ssh/.ssh/config
```
Expected: one match each.

- [ ] **Step 5: Statically validate the edited files parse and the SSH Include ordering (Review Focus: first-match)**

The public repo is unstowed at this point, so validate the repo files directly rather than via `$HOME`:
```bash
bash -n ~/dotfiles/bash/.bash_common && echo "bash_common syntax ok"
git config -f ~/dotfiles/git/.gitconfig --list >/dev/null && echo "gitconfig parses"
ssh -F ~/dotfiles/ssh/.ssh/config -G github.com >/dev/null 2>&1 && echo "ssh config parses"
awk '/Include ~\/\.ssh\/config\.d/{i=NR} /^Host \*/{h=NR} END{ if(i>0 && h>0 && i<h) print "config.d Include precedes Host * (ok)"; else print "ORDER PROBLEM" }' ~/dotfiles/ssh/.ssh/config
```
Expected: `bash_common syntax ok`, `gitconfig parses`, `ssh config parses`, `config.d Include precedes Host * (ok)`.
