# Gram Configuration folder

This is my config. It may or may not work for you.  I come from emacs and my fingers are now also adapted to working on a Mac all day.

So this is my crazy but works for me key mapping.

Gram reads `settings.jsonc` and `keymap.jsonc` (not the `.json` names Zed uses), so this
package must keep the `.jsonc` extensions or the stowed symlinks are silently ignored.

Stowed from the dotfiles repo with `make stow` / `make restow`, which links this folder
into `~/.config/gram`.
